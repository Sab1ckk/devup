# Реализация upup-auth-and-order-plan

## Реализовано

- React/JavaScript, Router, семь страниц с сохранением исходных CSS, SVG, разметки и текстов. Эталон находится в template; UPUP не изменён.
- Сквозная навигация, меню, диалоги, палитра, темы, уведомления, эффекты появления/подсветки/кнопок, сортировка отзывов.
- Регистрация и вход: Argon2id, обязательный код из письма, сроки, повторная отправка, ограничения попыток, серверные сессии, выход и CSRF-проверка.
- SMTP/console за отдельным интерфейсом, HTML/text письма, фоновая доставка и безопасный журнал статусов. Console намеренно не раскрывает коды в логе.
- Конструктор из 26 общих блоков, одиночные экземпляры, drag-and-drop, кнопки перестановки, клавиатурный фокус и объявления изменений. Общий JSON читается обоими приложениями.
- Контакты, гостевые и пользовательские заявки, черновик, одноразовый показ кода, копирование и печать/PDF. Вложения остаются макетом.
- Кабинет, детали, контакты, история, привязка по коду, браузеру или подтверждённой почте; атомарная защита от смены чужого владельца.
- Таблицы чата без API чата, CLI статусов/менеджера/очистки, периодическая очистка, Compose PostgreSQL+Mailpit, README.

## Принятые умолчания и совместимость

JavaScript/JSX используется по прямому указанию пользователя вместо TypeScript из плана. Приняты React Router, Vitest, React Testing Library, синхронный SQLAlchemy, psycopg 3 и область вложений как макет. Старые таблицы сохраняются; новые заявки используют requests. Сохранены старые роли, новым пользователям назначается client. Сервер PostgreSQL владельца версии 18 сохранён, Compose использует 16.

## Проверки

- pytest: 19 сценариев на отдельной PostgreSQL devup_test, включая конкурентную привязку, лимиты, коды, сессии, права и ошибки SMTP.
- Vitest/React Testing Library: 6 проверок общего каталога и конструктора.
- Playwright: все семь страниц на 360/768/1280, две палитры; пиксельное сравнение пяти неизменённых страниц с template; меню, сортировка, гостевая заявка, восстановление/очистка черновика, код, регистрация, предложение привязки, кабинет и детали.
- SMTP-письмо доставлено локальному Mailpit через настоящий smtplib.
- Сборка Vite, ESLint; применение/откат/повторное применение миграций на devup_test.

Gmail SMTP настроен в локальном .env владельца. Тестовое письмо принято сервером smtp.gmail.com через STARTTLS; доставка также проверена через локальный Mailpit. Секреты не включены в исходники и отчёт. Проверка папки «Входящие» выполняется владельцем почты.
